# AjGolf AI · รุ่นที่สาม

ค้นด้วยเวกเตอร์ · ตอบคำถาม · ใช้ OpenRouter เจ้าเดียว กุญแจอันเดียว · วางบน GitHub Pages

---

## โครงไฟล์

```
index.html            หน้าเว็บแชตบอต
config.js             ไฟล์ตั้งค่า  กุญแจอยู่ที่นี่
build-vectors.html    เครื่องมือสร้างไฟล์เวกเตอร์  ใช้ครั้งเดียว
vectors.json          สร้างจากเครื่องมือข้างบน  ยังไม่มีในชุดนี้
01-leave.txt ... 08-contact.txt   เอกสารแปดไฟล์
```

---

## แนวคิดของรุ่นนี้

| ขั้น | ทำที่ไหน | เรียก API กี่ครั้ง |
|---|---|---|
| หั่นเอกสาร | เบราว์เซอร์ | 0 |
| แปลงเอกสารเป็นเวกเตอร์ | **ทำล่วงหน้าครั้งเดียว** | 1 ครั้งตลอดกาล |
| แปลงคำถามเป็นเวกเตอร์ | เบราว์เซอร์ | 1 ครั้งต่อคำถาม |
| ตอบคำถาม | เบราว์เซอร์ | 1 ครั้งต่อคำถาม |

รุ่นแรกเรียก API 16 ครั้งทุกครั้งที่เปิดหน้าเว็บ  **รุ่นนี้เหลือ 0 ครั้ง**

## สองโหมดการค้นหา

แก้บรรทัดเดียวใน config.js

```javascript
SEARCH_MODE: "vector",   // หรือ "local"
```

| โหมด | ค้นอย่างไร | ต้องมีอะไร |
|---|---|---|
| `vector` | ความหมาย  ตรงกับที่สอนในสไลด์ | ไฟล์ vectors.json |
| `local` | เทียบตัวอักษรในเบราว์เซอร์ | ไม่ต้องมีอะไรเลย |

**ถ้าโหมด vector มีปัญหา ระบบจะถอยไปใช้ local ให้เองอัตโนมัติ**
เว็บจึงไม่มีวันใช้งานไม่ได้ และจะขึ้นข้อความบอกว่าสลับโหมดแล้ว

ทุกคำตอบจะบอกด้วยว่าค้นด้วยวิธีไหน จึงตรวจสอบได้

## วิธีติดตั้ง

### ขั้นที่ 1 ขอกุญแจหนึ่งอัน

ขอที่ openrouter.ai ที่เมนู Keys  กุญแจขึ้นต้นด้วย `sk-or-`

**ใช้อันเดียวทั้งแปลงเวกเตอร์และตอบคำถาม**

### ขั้นที่ 2 สร้าง repo แบบ Public แล้วอัปไฟล์ทั้งหมด

ลากไฟล์ทั้งหมดเข้าไปทีเดียว ไม่มีโฟลเดอร์ย่อย

### ขั้นที่ 3 แก้ config.js

```javascript
KEY: "sk-or-v1-xxxxx",
SEARCH_MODE: "vector",
EMBED_MODEL: "nvidia/nemotron-3.5-embed-1b:free",
MODEL: "google/gemma-4-31b:free",
```

### ขั้นที่ 4 เปิด GitHub Pages

Settings แล้ว Pages แล้ว Deploy from a branch แล้ว main แล้ว / (root)

### ขั้นที่ 5 สร้างไฟล์เวกเตอร์

เปิด `https://ชื่อผู้ใช้.github.io/ชื่อrepo/build-vectors.html`

วางกุญแจ OpenRouter แล้วกดเริ่มสร้าง แล้วกดดาวน์โหลด

**จากนั้นอัป vectors.json ขึ้น repo** ชั้นเดียวกับ index.html

### ขั้นที่ 6 ทดสอบ

เปิดหน้าหลัก ควรขึ้น

```
พร้อมใช้งาน   เอกสาร 8 ไฟล์  16 ชิ้น   ค้นแบบเวกเตอร์   ตอบด้วย OpenRouter
```

ถ้าขึ้นว่า ค้นแบบเทียบตัวอักษร แปลว่าโหมดเวกเตอร์ยังไม่ทำงาน
ให้กด F12 ดูแท็บ Console จะมีข้อความบอกสาเหตุ

## ทดสอบสามข้อ

| คำถาม | คำตอบที่ควรได้ |
|---|---|
| ลาป่วยกี่วันต้องมีใบรับรองแพทย์ | 5 วันขึ้นไป อ้าง 01-leave.txt |
| ลาพักการศึกษาได้กี่ภาค | ไม่เกิน 2 ภาค อ้าง 07-faq.txt |
| หอพักค่าเช่าเท่าไร | ไม่พบข้อมูลในเอกสารของคณะ |

### ข้อทดสอบพิเศษสำหรับโหมดเวกเตอร์

ลองถามว่า **ขออนุญาตหยุดเรียนเพราะไม่สบายต้องทำยังไง**

คำถามนี้ไม่มีคำว่า ลาป่วย อยู่เลย

- โหมด vector ควรค้นเจอ 01-leave.txt
- โหมด local อาจค้นไม่เจอ

**นี่คือข้อที่แสดงความต่างของสองวิธีได้ชัดที่สุด** และตรงกับสไลด์หน้า 13

---

## ถ้าแก้เอกสาร

ต้องสร้าง vectors.json ใหม่ด้วย โดยเปิด build-vectors.html แล้วทำซ้ำ

ถ้าลืม ระบบจะยังใช้เวกเตอร์ของเอกสารเก่าอยู่

## ตารางแก้ปัญหา

| อาการ | สาเหตุ | วิธีแก้ |
|---|---|---|
| ขึ้นว่าค้นแบบเทียบตัวอักษร ทั้งที่ตั้ง vector | ยังไม่มีไฟล์ vectors.json | สร้างจาก build-vectors.html แล้วอัป |
| อ่าน vectors.json ไม่ได้ | ยังไม่ได้อัปไฟล์ | สร้างจาก build-vectors.html แล้วอัป |
| แปลงคำถามไม่สำเร็จ 401 | กุญแจผิด | ตรวจว่าขึ้นต้นด้วย sk-or- |
| 429 | โควตาหมด | ระบบถอยไป local ให้เอง รอแล้วลองใหม่ |
| ไม่พบรุ่นแปลงเวกเตอร์ | ชื่อรุ่นเปลี่ยน | ดูที่หน้า Models แท็บ Embeddings |
| model not found | ชื่อรุ่นเปลี่ยน | คัดลอกชื่อใหม่จากหน้า Models |
