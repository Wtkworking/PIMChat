สร้างไฟล์เวกเตอร์

เครื่องมือนี้ใช้ครั้งเดียวตอนเตรียมเอกสาร ไม่ได้เป็นส่วนหนึ่งของเว็บแชตบอต

ทำอะไร

  1. อ่านไฟล์เอกสารทั้งหมดตามรายการใน config.js
  2. หั่นเป็นชิ้นเล็ก
  3. ส่งไปให้ OpenRouter แปลงเป็นเวกเตอร์ ครั้งเดียว
  4. ให้ดาวน์โหลดไฟล์ vectors.json ออกมา

จากนั้นเอาไฟล์นั้นอัปขึ้น GitHub ชั้นเดียวกับ index.html
เว็บแชตบอตจะโหลดไฟล์นี้ไปใช้ จึงไม่ต้องแปลงเอกสารซ้ำอีกเลย

พร้อมเริ่ม กุญแจที่ใส่จะอยู่ในเบราว์เซอร์นี้เท่านั้น ไม่ถูกบันทึกที่ไหน
